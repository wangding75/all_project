# 闪现 (sx)

基于 **BlackBox 应用虚拟化沙箱** 的多开隔离与环境伪装 App。  
产品功能与 **UI 信息架构参照星盒 (xh)**，引擎与业务代码自研/开源合规集成，**不使用未授权商业 VA 源码**。

> [!IMPORTANT]
> **软件状态说明**：当前仓库版本为 **功能内测基线 (RC)**，用于技术验证与功能走查；**非商业可售版本**。  
> 钉钉等特定应用专项适配未完成；且实机交互回归测试已后置到统一设备测试波次，未经实机点按测试前不得宣称全功能可用。

## 编译与构建说明

### 1. 编译环境
- **Android Studio**: Jellyfish / Iguana 及以上
- **JDK**: 17
- **Compile SDK**: 34
- **Min SDK**: 26 (Android 8.0)

### 2. 构建命令
```bash
# 构建 Debug 包
./gradlew :app:assembleDebug

# 构建 Release 包 (已开启 R8 混淆优化与 Keep 规则)
./gradlew :app:assembleRelease
```

## 快速使用指南

1. **激活授权**
   - 首次启动显示 Splash 授权界面，或在「我的」->「授权管理」中激活。
   - 开发/内测开发卡密：`SX-DEV-20991231` (有效期至 2099-12-31)。
2. **沙箱多开**
   - 在「应用」Tab 点击「添加应用」，从设备应用列表中选择要导入 App。
   - 支持启动、多实例克隆 (userId)、清除沙箱数据与卸载分身。
   - 支持向桌面发送分身快捷方式。
3. **环境伪装**
   - **虚拟定位**：支持地图选点与经纬度配置，具有 50ms 注入与反 Mock 检测。
   - **设备伪装**：随机或自定义 IMEI、Android ID、BUILD 厂商模型与 SIM 卡数据。
   - **网络伪装**：伪造当前 WiFi (SSID/BSSID) 及周围 WiFi 扫描列表。
   - **虚拟相机**：支持 PreviewCallback 级图像帧替换。
   - **伪装探针**：在「我的」->「环境伪装探针」查看当前伪装生效读数。
4. **用户协议与隐私政策**
   - 可在「我的」Tab 点击「用户协议与隐私政策」查看详细法律合规与隐私条款。
