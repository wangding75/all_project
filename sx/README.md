# 闪现 (sx)

基于 **BlackBox 应用虚拟化沙箱** 的多开隔离与环境伪装 App。  
产品功能与 **UI 信息架构参照星盒 (xh)**，引擎与业务代码自研/开源合规集成，**不使用未授权商业 VA 源码**。

---

## 技术选型摘要

| 项 | 选择 |
|----|------|
| 沙箱 | BlackBox 自维护 fork |
| UI | 参照 xh（星盒）页面流 |
| 伪装 | 沙箱内 Hook（定位/设备/WiFi·基站/相机） |
| 授权 | 自研卡密 + 离线 Token |
| 系统 | 主支持 Android 10–13 |
