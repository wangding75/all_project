## 1. 测试目标

| 目标 | 说明 |
|------|------|
| 主目标 | 验证 **Debug APK 可安装、可启动**，主路径可点通 |
| 次目标 | 多开 / 伪装 / 相机（限定范围）/ 授权拦截 在模拟器上的表现 |
| 非目标 | 钉钉专项完整验收（Wave 0/2）；商业授权；宣称商业可售 |

**产品口径：** 钉钉为首发卖点，但 **本场不强制测钉钉**（可选加测，结果单独记）；默认先通用路径。

## 2. 环境准备

### 2.1 模拟器建议

| 项 | 建议 |
|----|------|
| AVD | Pixel 5 / Pixel 6 等通用镜像 |
| 系统 | **API 29～33** 优先（与 BB 笔记一致）；API 34 可测但异常多记已知问题 |
| ABI | 与本机构建一致（常见 x86_64 模拟器） |
| 工具 | Android Studio + ADB |

### 2.2 打包与安装

在 **`sx/`** 目录：

```powershell
cd D:\github\all_project\sx
.\gradlew.bat :app:assembleDebug
adb devices
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

| 项 | 值 |
|----|-----|
| 包名（debug） | `com.sx.app.debug` |
| 产物 | `app\build\outputs\apk\debug\app-debug.apk` |
| 开发卡密 | `SX-DEV-20991231`（格式 `SX-DEV-YYYYMMDD`） |

若安装失败：记录错误全文（签名冲突可先 `adb uninstall com.sx.app.debug`）。
