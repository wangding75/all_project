## 一、 测试流程与用例汇总

根据 `docs/开发指令_Phase4.md` 四、回归最低路径，包含以下 5 项关键测试路径：

1. **激活授权流程**：安装 APK → SplashActivity 启动 → 输入开发卡密 `SX-DEV-20991231` 激活 → 进入主界面三 Tab（首页、应用、我的）。
2. **沙箱多开管理**：导入应用（已安装应用列表） → 启动沙箱分身 → 创建多实例克隆 (userId) → 清除沙箱应用数据 → 卸载/移除沙箱应用。
3. **环境伪装探针校验**：开启位置/设备/网络伪装配置 → 启动环境伪装探针 (`SpoofProbeActivity`) 或在分身内运行 Probe → 校验 Location/Device/WiFi/Cell Hook 读数。
4. **相机预览伪装验证**：开启相机伪装 + 选择本地替代图片源 → 验证 PreviewCallback 类场景 / 模拟相机的图像替换效果。
5. **未激活拦截机制**：无有效卡密或授权过期状态下，启动沙箱分身与核心 Hook 功能被拦截并弹出 Toast 明确提示。
