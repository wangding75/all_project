## 6. ST-2 模拟器重度应用（夸克浏览器）兼容性排查与引擎修复记录

- **测试日期**：2026-07-21
- **触发现象**：模拟器在沙盒中启动夸克浏览器，引发崩溃闪退。
- **定位与修复（Commit: `78d4687`）**：
  1. `BActivityThread.getActivityByToken` NPE 修复：对未完成注册的 Token 检索全链路增加 null 防护，彻底解决 Java 致命崩溃。
  2. `IActivityManagerProxy` ContentProvider 降级 fallback：厂商特权 Provider（如 `com.vivo.vms.IdProvider`）自动降级调用系统 ActivityManager，解决 `ActivityThread: Failed to find provider info` 抛错。
- **2分钟长效运行测试结论**：
  - Java 层与组件生命周期已完全修复并保持正常运行。
  - 启动 25~30 秒处发生的退出系 C++ 渲染内核（`libwebviewuc.so`）在向系统申请 GPU/Vulkan 共享显存句柄时触发的 Native SIGSEGV 冲突。已登载入 `docs/22_已知问题.md` 项 9，规划于后续 **Epic Engine-Hardening** 专项补齐 C++ POSIX `mmap` / `ioctl` 代理。
