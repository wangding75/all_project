## 二、 已知技术限制与边界 (Known Limitations)

### 1. 虚拟相机 (Virtual Camera) 限制

- **支持范围**：仅支持标准 `Camera.PreviewCallback` 级别的 NV21/YUV 图像帧拦截与替换。
- **暂不支持**：
  - Camera2 API 的全量 Surface / SurfaceTexture 纹理强行替换；
  - 视频循环解码（MP4 硬件解码动态渲染）；
  - 3D/AR 等高阶相机硬件底层操作。
- **详见文档**：`docs/18_Camera策略限制说明.md`。

### 2. 卡密与授权机制

- **当前实现**：使用开发/内测本地 HMAC 算法校验机制。
- **DEV 卡密**：`SX-DEV-20991231` (有效期至 2099-12-31，用于内测与调试)。
- **限制**：未接入商业服务端在线实时订单/卡密中台，防回拨时钟通过网络 NTP/SNTP 异步校验。

### 3. 系统与 ROM 兼容性限制

- **Android 14/15 适配**：本阶段主要面向 Android 8.0 - Android 13 通用 Rom；针对 Android 14/15 的高版本 SELinux/沙箱限制仅作基本运行适配，未做全面专项保证。
- **定制 ROM 差异**：个别厂商深度定制 ROM（如部分 HarmonyOS / OriginOS 强管控系统）可能对悬浮窗/快捷方式权限或反射 Hook 有额外限制，需手动允许相关权限。

### 4. 强检测应用与高阶防封

- **定位**：当前提供基础反 Mock (`isFromMock=false`)、设备全字段伪装、WiFi/基站信息伪装。
- **限制**：未包含高级内核级防检测（如 Kernel VMP、Syscall 绕过、Hardware-level Attestation），遇到金融级/强反作弊检测 App 可能存在被检测到的风险。

### 5. 相机跨进程数据读取路径白名单限制 (Camera Path Security Whitelist)

- **实现说明**：`ConfigProvider.get_camera_bytes` 已限制为仅允许读取 Host 应用的专用相机目录（`getExternalFilesDir("camera")`、`getFilesDir()/camera` 以及 cache 目录），拒绝任意文件路径读取请求。
- **限制**：选择媒体文件时需放置在允许的相机沙箱存储路径下。

### 6. 实机/模拟器点按回归后置说明

- **当前状态**：当前 RC 交付仅完成了代码实现、逻辑走查与 `assembleDebug` / `assembleRelease` (含 R8) Gradle 编译构建验证。完整模拟器与通用真机的 UI 交互点按测试已后置到统一设备测试波次，非本轮完成项。

### 7. targetSdk 33（技术债）
- **说明**：为兼容 Android 14/15/16 沙箱引擎，客户端 targetSdk 临时降至 33。
- **影响**：部分 Android 14+ 系统行为差异，以及未来 Google Play 上架要求（Play 要求 targetSdk≥34）。
- **计划**：待沙箱引擎适配 Android 14 后（Epic G-04）专项提升。

### 9. 重度 C++ 渲染内核应用（夸克/UC浏览器/大型游戏等）沙盒长效兼容性限制

- **现象说明**：夸克浏览器等集成了 64 位自研 C++ WebView 渲染内核（`libwebviewuc.so`）的应用，在沙盒环境中启动约 25~30 秒后，其 C++ 原生引擎在申请 OpenGL/Vulkan 显存及共享内存句柄时，会在 C++ Native 层触发 `SIGSEGV` 信号崩溃。此外，读取厂商特权 Provider（如 `com.vivo.vms.IdProvider`）曾引发 `ActivityThread` 空指针。
- **已完成修复**：已在 Commit `78d4687` 中完成 `BActivityThread` 空指针防护与 `IActivityManagerProxy` 的 ContentProvider 存根系统级 fallback 降级机制，彻底解决了 Java 层的致命崩溃。
- **后续规划**：重度 C++ 应用的 2 分钟及长效稳定运行，需在后续 **Epic Engine-Hardening (沙盒 Native C++ 内核加固)** 专项中，针对 `NativeCore`（C++ 层）补充 POSIX `mmap` 共享内存段代理与 GPU `ioctl` 系统调用管道拦截。
