## 2. 本场测试目标（修正后）

### 2.1 主目标（必达才算 ST-1 PASS）

| ID | 目标 | 通过标准 |
|----|------|----------|
| **G1** | 可安装可启动 | Debug APK 安装成功；冷启动进主界面不闪退 |
| **G2** | 授权主路径 | DEV 卡密 `SX-DEV-20991231` 可激活；三 Tab 可用 |
| **G3** | 多开主路径 | 导入 **轻量 App** → 启动分身进界面 → 克隆 → 清数据 → 卸载，无阻断崩溃 |
| **G4** | 授权门闸 | 未激活/过期时启动分身失败且有明确提示（非「假成功」） |
| **G5** | 配置可保存 | 定位/设备/网络/相机设置保存后杀进程再进仍在 |

### 2.2 次目标（尽量测，失败记缺陷不直接否决 ST-1）

| ID | 目标 | 通过标准 / 说明 |
|----|------|-----------------|
| **G6** | 分身内伪装可读 | 分身内探针或可读场景：定位/设备/WiFi 与配置大体一致（改配置后需 **杀分身再进**） |
| **G7** | 相机（限定） | 仅验证 **Camera1 PreviewCallback** 相关路径有替换迹象；Surface 真画面 **不记 FAIL**，记「符合 docs/18 限制」 |
| **G8** | Release 包 | 可选：装 release 冷启动一次（本场非必须） |

### 2.3 非目标（本场明确不做 / 不做必过）

| 非目标 | 说明 |
|--------|------|
| **钉钉任何测试** | **本场完全跳过**，不安装、不启动、不摸底；归钉钉专项另场进行 |
| 全机型、Android 14/15 保证 | 记现象即可 |
| Camera2 / Surface 纹理替换 / 视频循环 | 已知未做，本场不验收 |
| 商业卡密、上架、VMP | 产品级，不在本场 |
| 宣称「功能 RC 真机全绿」「商业可售」「钉钉可用」 | **禁止** |

### 2.4 一句话目标

> **ST-1 核心：在模拟器上证明闪现「能打开（装得上、启得动、激活通）+ 能多开（导入→启动→克隆→清数→卸载全路径无阻断崩溃）」。钉钉本场完全跳过；伪装/相机/Release 为可选加分项。**

## 3. 范围与优先级

```text
P0 必测（本场核心）：
  G1 安装启动   — 装得上、冷启动进界面
  G2 激活主路径 — DEV 卡密激活、三 Tab 可用
  G3 多开主路径 — 导入轻量 App → 启动分身 → 克隆 → 清数据 → 卸载，无阻断崩溃
  G4 授权门闸   — 未激活时启动分身被拦截
  G5 配置持久化 — 定位/设备/网络/相机保存后杀进程仍在

P1 抽测（本场有余力时做）：
  G6 分身内伪装读数
  G7 相机 PreviewCallback 替换迹象

P2 可选（有时间时做）：
  G8 Release 包冷启动

钉钉：本场完全不测，不在任何优先级列表内。
```

**多开用 App：** 优先**系统计算器 / 系统浏览器 / 简单工具**，不使用钉钉。

## 6. 本场结论判定

| 判定 | 条件 |
|------|------|
| **ST-1 PASS（仅模拟器）** | G1～G5 全 PASS；无 S/A 级未关闭阻断 |
| **有条件通过** | G1～G5 基本过，存在 B 级问题已记录 |
| **不通过** | 无法安装/启动，或多开主路径必现崩溃/无法导入 |

**ST-1 PASS ≠ 真机 RC 完成 ≠ 钉钉专项完成 ≠ 商业可售。**
