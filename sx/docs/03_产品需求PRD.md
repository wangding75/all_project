# 闪现 (sx) 产品需求文档 (PRD)

> 功能范围对标 `xh/docs/prd_functional_requirements.md`，产品名与实现选型按闪现方案裁剪。

---

## 0. 目标与非目标

### 目标

- 提供可用的应用多开与数据隔离  
- 提供分身级环境伪装（定位 / 设备 / 网络 / 相机）  
- UI 与操作路径接近星盒，降低学习成本  

### 非目标（一期）

- 完整再造商业 VA  
- 对全量加固/强检测 App 的保证过检  
- 云端账号体系（可用本地卡密替代）  
- 两仪式完整子系统虚拟机

## 1. M1 独立多开沙箱 — P0

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| F-1.1 | 从已安装列表导入 App 到沙箱 | P0 | 可选中非系统应用，显示安装进度，成功后出现在列表 |
| F-1.2 | 数据隔离存储 | P0 | 分身数据目录与宿主/真机同包数据分离；清数据不影响真机 App |
| F-1.3 | 同一应用多实例 | P0 | 至少支持 2 个 userId 实例，数据互不影响 |
| F-1.4 | 桌面快捷方式 | P0 | 创建后点击可启动对应 `pkg+userId` |
| F-1.5 | 启动 / 停止 / 卸载 / 清数据 | P0 | 列表与详情页可操作，有确认弹窗 |
| F-1.6 | 重命名分身显示名 | P1 | 仅改标签，不改包名 |
| F-1.7 | 独立虚拟设置入口 | P0 | 可为单个分身覆盖全局伪装配置 |

**xh 对应界面：** `ListAppActivity` / `ListAppActivity2`、主页应用区、快捷方式 `create_shortcut`。

## 2. M2 虚拟定位 — P0

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| F-2.1 | 地图/地点选点 | P0 | 一期：POI 列表+搜索+手动输入；二期：地图 SDK |
| F-2.2 | 经纬度/海拔/精度注入 | P0 | 分身内定位 API 读到配置值 |

| F-2.4 | 微漂移/轨迹（基础） | P1 | 开关微漂移；轨迹二期 |

| F-2.6 | 全局 / 分身定位配置 | P0 | 独立设置可覆盖 |

**xh 对应：** `LocationSettingsActivity`、`LocationSearchActivity`、`FackLocService`；标题「虚拟地理位置」「地点选择」。

## 4. M4 设备指纹 — P0

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| F-4.1 | IMEI / MEID / Android ID | P0 | 分身内读取为伪造值（高版本 IMEI 可能为空属预期） |

| F-4.4 | 随机生成 / 重置本机 | P0 | 一键随机与清空恢复 |
| F-4.5 | 总开关 | P0 | 关闭后不伪装 |

**xh 对应：** `PhoneSettingsActivity`、`DeviceSelectActivity`；文案 `device_virtual_notice`。

## 6. M6 授权与安全 — P0/P1

| ID | 需求 | 优先级 | 验收标准 |
|----|------|--------|----------|
| F-6.1 | 卡密激活 | P0 | 合法卡密可激活并持久化 |
| F-6.2 | 离线到期校验 | P0 | 过期后核心功能不可用或只读 |
| F-6.3 | 防时钟回拨 | P1 | 回拨系统时间不能延长授权 |
| F-6.4 | 代码加固 | P2 | 发布包开启混淆；核心可选 so 化 |

**xh 对应：** `ActiveCardActivity`、`SplashActivity` 登录态分支。

## 7. 非功能需求

| ID | 项 | 要求 |
|----|----|------|
| N-1 | 性能 | 列表 50 应用内滑动流畅；定位线程不 ANR |
| N-2 | 兼容 | 至少 2 款真机 + 1 模拟器，Android 10 与 13 各一 |
| N-3 | 稳定性 | 连续启动分身 20 次无 Host 崩溃 |
| N-4 | 隐私 | 隐私协议入口；权限最小化说明 |
| N-5 | 可维护 | 引擎与 UI 解耦，接口单测/假实现可跑通 UI |

---

## 8. 用户角色与主路径

1. 安装闪现 → 同意协议 →（可选激活）→ 主页  
2. 添加应用 → 列表出现 → 启动分身  
3. 虚拟设置配置定位/设备 → 再进分身验证  
4. 长按 → 克隆 / 快捷方式 / 独立设置
