# UI / 交互规格（参照星盒 xh）

## 1. 设计原则

1. **信息架构对齐星盒**，用户从 xh 迁移时零学习成本  
2. 品牌文案使用「闪现」，不出现「星盒」  
3. 一期 Material 简洁风；颜色可自定（建议主色蓝 `#1A73E8`）  
4. 关键操作用途明确，危险操作二次确认  

---

## 2. 页面地图（对照 xh）

| 闪现页面 | 对照 xh Activity | 说明 |

## 3. 导航结构

```
Splash
  ├─(未激活且强制)→ License
  └─→ Main
        ├─ Tab 首页 (home_page)
        │     └─ 模块卡片 → 各 Settings / 应用列表
        ├─ Tab 应用 (my_apps)
        │     └─ 沙箱 App 列表 → 详情 / 添加
        └─ Tab 我的 (me)
              ├─ 授权管理
              ├─ 关于
              └─ 版本信息
```

对齐 xh 底部：`首页` / `我的应用` / `我的`。

## 4. 关键页面线框说明

### 4.1 启动页 Splash

- 全屏品牌背景 + Logo + 标语（例：多开隔离 · 环境伪装）  
- 2s 内完成：协议（首次）、授权状态、跳转  
- xh 有「虚拟环境/Xposed 检测」类拦截；闪现 **默认不拦截 LSPosed**（自身可能是模块），仅可选提示  

### 4.2 激活页 License（对照 ActiveCard）

| 元素 | 说明 |
|------|------|
| 设备 ID | 可复制，用于绑卡 |
| 卡密输入框 | hint：输入激活码 |
| 激活按钮 | 成功 → Main；失败 Toast |
| 状态文案 | 已激活显示到期时间 |

一期不做短信验证码/注册邮箱（xh 有，可二期）。

### 4.3 首页 Home

**状态卡：**

- 引擎/模块状态（沙箱是否就绪）  
- 授权状态  

**功能入口卡（顺序建议对齐使用频率）：**

1. 沙箱多开 → 应用 Tab 或 AppList  
2. 虚拟定位 → LocationSettings  
3. 设备伪装 → DeviceSettings  
4. 网络伪装 → NetworkSettings  
5. 虚拟相机 → CameraSettings  
6. 授权管理 → License  

副标题文案可参考 xh：`virtual_settings_hint`「可以在此设置虚拟信息」。

### 4.4 应用列表（对照 ListAppActivity）

| 元素 | 行为 |
|------|------|
| 空状态 | 「您还没有添加任何程序哦~~」类文案 |
| 网格/列表项 | 图标 + 名称 + 分身角标 `#2` |
| 单击 | 启动分身 |
| 长按 / 更多 | 弹出菜单 |
| FAB「添加」 | 进入 AppPicker |

**长按菜单（对齐 xh）：**

| 菜单项 | xh 文案参考 | 动作 |
|--------|-------------|------|
| 启动 | — | launch |
| 添加新应用 | add_app | AppPicker |
| 克隆 App | clone_apps | clone → 新 userId |
| 卸载应用 | — | 确认后 uninstall |
| 清除数据 | — | 确认后 clear |
| 创建快捷方式 | create_shortcut | pin shortcut |
| 独立设置 | app_settings / 独立设置 | 带 pkg+userId 进设置页 |
| 重命名 | rename | 对话框 |

独立设置确认文案对齐：`您是否要对%s进行单独虚拟设置`。

### 4.5 添加应用 AppPicker

- 异步加载已安装第三方 App  
- 多选或单选导入（一期单选即可）  
- 安装中：`正在安装 %s` / 成功提示  
- 限制：可配置单次上限（xh：不宜一次过多）  

### 4.6 应用详情 AppDetail

- 大图标 + 名称 + 包名 + userId  
- 按钮区：启动、克隆、快捷方式、清除数据、移除  
- 入口：独立设置（定位/设备/网络快捷跳转，带 scope）  

### 4.7 虚拟地理位置（对照 LocationSettings）

标题：`虚拟地理位置` / `虚拟定位`

| 控件 | 说明 |
|------|------|
| 总开关 | 启用位置模拟 |
| 坐标展示 | `坐标：纬度 %.8f；经度 %.8f` |
| 纬度/经度输入 | 校验 -90~90 / -180~180 |
| 精度、更新间隔 | 默认精度 2m，间隔 50ms |
| 微漂移开关 | 可选 |
| 反 Mock 开关 | 默认开 |
| 地图选点 | → LocationPicker |
| 随机位置 | 以当前点为中心小范围随机 |
| 保存 / 启动模拟 | 写配置；可选起前台服务 |

未开模拟位置引导（若走 TestProvider）：对齐开发者选项三步说明。

**作用域：** 顶栏或 Switch：`全局设置` / `独立设置`（有 pkg 时）。

### 4.8 地点选择（对照 LocationSearch）

标题：`地点选择`

- 搜索框：支持 `城市@关键词`  
- 一期：内置城市地标列表 + 过滤  
- 底部：当前坐标预览 + 确认  
- 返回：`lat` / `lng` / `address`  

### 4.9 设备模拟（对照 PhoneSettings）

标题：`设备模拟` / `伪造设备信息`

- 总开关  
- 说明区：对齐 `device_virtual_notice` 五条提示  
- 字段：品牌、型号、制造商、主板、序列号、IMEI、MEID、Android ID、手机号、IMSI、ICCID、运营商  
- 按钮：随机生成、重置为真实、保存  

### 4.10 网络伪装（对照 WifiSettings + 基站）

- 总开关  
- SSID、BSSID、MAC  
- MCC/MNC/LAC/CID  
- 扫描列表多行编辑：`SSID,BSSID,level`  
- 随机 / 保存  

### 4.11 虚拟相机

- 总开关  
- 源类型：视频 / 图片  
- 当前路径展示  
- 选择媒体  
- 保存  
- 未设置提示：对齐「请先设置模拟照片/视频」  

### 4.12 我的

- 版本号  
- 设备 ID  
- 授权入口  
- 关于/用户协议/隐私政策

## 5. 全局交互规范

| 场景 | 规范 |
|------|------|
| 加载 | 列表 Progressive；安装 App 用对话框进度 |
| 错误 | Toast 短文案；权限用 Dialog 引导设置 |
| 返回 | 设置页未保存可丢弃（一期不强制草稿） |
| 权限 | 定位、存储/媒体、通知（前台服务）、查询应用列表 |

## 7. 视觉备注

- 列表卡片圆角 12dp、轻阴影（已有 `Sx.Card` 风格可延续）  
- 主色与 xh 不必一致，避免品牌混淆  
- 图标：一期系统/矢量占位；二期统一 icon 集
