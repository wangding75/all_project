## 1. 核心决策

| 决策项 | 结论 |
|--------|------|
| 服务端形态 | **本项目自建服务端**（独立部署，管理卡密全生命周期） |
| 三方卡网角色 | **仅负责收款+自动发货**，通过回调从本服务端取卡密，不直接与客户端通信 |
| 客户端对接 | **只和本项目服务端通信**，不直接调任何三方卡网接口 |
| 卡密策略 | 简单策略，时长自定义；1 台设备绑定 |
| 设备绑定 | AndroidID SHA-256 哈希 |
| 本地存储 | EncryptedSharedPreferences |
| 离线策略 | 本地 Token 到期前可用，依赖 TimeGuard 可信时间 |
| DEV 卡密 | 仅 debug 包保留，release 拒绝 |

## 2. 三实体架构

```
┌──────────────────┐      ┌─────────────────────────┐      ┌──────────────────┐
│   三方卡网        │      │      本项目服务端          │      │  客户端（Android）│
│（爱发卡/发卡网等）│      │（独立部署，项目自建）       │      │                  │
└──────────────────┘      └─────────────────────────┘      └──────────────────┘

  用户付款
      │
      │ 自动发货 Webhook
      └──────────────────► POST /api/cards/deliver
                           服务端生成/取出卡密
                           返回 {"card_key":"SX-XXXX"}
      ◄──────────────────
      │ 卡网把卡密发给用户
      
                                                              用户手动输入卡密
                                                                     │
                                            POST /api/license/activate
                                            body: {card_key, device_id}◄─┘
                                            服务端校验卡密 + 绑定设备
                                            返回 {token, expire_at}
                                                              ────────►
                                                              本地加密存储 Token

                                            GET /api/license/verify   ◄─── 启动时后台刷新
                                            header: Authorization: Bearer {token}
                                            query: device_id={deviceId}
                                            返回 {valid, expire_at}

                                            POST /api/license/unbind  ◄─── 管理员后台操作
                                            （解绑设备，允许用户换机）
```

## 3. 职责边界（明确分工）

| 实体 | 职责 | 不负责 |
|------|------|--------|
| **三方卡网** | 收款 · 用户通知 · 调发货接口获取卡密 · 自动发送卡密给用户 | 卡密生成、鉴权、设备绑定 |
| **本项目服务端** | 卡密生成/管理 · 激活/核销 · 设备绑定/解绑 · 客户端鉴权 · 发货接口 | UI（纯 API 服务） |
| **客户端** | 提交卡密激活 · 本地存 Token · 启动时鉴权 · 展示授权状态 | 直接调三方卡网 |

## 4. 本项目服务端设计

### 4.1 技术选型建议

| 项 | 建议 | 说明 |
|----|------|------|
| 语言/框架 | Python FastAPI 或 Node.js Express | 轻量，快速迭代 |
| 数据库 | SQLite（单机）/ MySQL（生产） | 存卡密、设备绑定、激活记录 |
| 部署 | Docker 单容器，反向代理 Nginx | 独立于客户端 |
| 认证 | HMAC-SHA256 签名（请求级别） | 防接口滥用 |

### 4.2 数据模型

```sql
-- 卡密表
CREATE TABLE cards (
    id          INTEGER PRIMARY KEY,
    card_key    VARCHAR(64) UNIQUE NOT NULL,   -- 如 SX-XXXX-XXXX-XXXX
    duration_days INTEGER NOT NULL,            -- 有效天数（-1=永久）
    status      VARCHAR(16) DEFAULT 'unused',  -- unused/activated/expired/revoked
    created_at  BIGINT NOT NULL,
    batch_id    VARCHAR(32)                    -- 批次 ID，便于管理
);

-- 激活记录表
CREATE TABLE activations (
    id          INTEGER PRIMARY KEY,
    card_key    VARCHAR(64) NOT NULL,
    device_id   VARCHAR(64) NOT NULL,          -- SHA-256 of AndroidID
    activated_at BIGINT NOT NULL,
    expire_at   BIGINT NOT NULL,               -- Unix ms；-1=永久
    token_hash  VARCHAR(64),                   -- 当前有效 Token 的哈希
    is_active   BOOLEAN DEFAULT TRUE,
    UNIQUE(card_key, device_id)
);
```

### 4.3 API 接口清单

#### 面向客户端

**激活卡密**
```
POST /api/license/activate
Content-Type: application/json

{
  "card_key": "SX-XXXX-XXXX-XXXX",
  "device_id": "sha256_of_android_id",
  "sign": "hmac_sha256(card_key+device_id+timestamp+secret)"
}

响应 200:
{
  "code": 200,
  "msg": "激活成功",
  "data": {
    "token": "eyJ...",       // JWT 或自定义 Token
    "expire_at": 1780000000000
  }
}

响应 400（卡密无效/已用/设备不匹配）:
{
  "code": 400,
  "msg": "该卡密已绑定其他设备"
}
```

**鉴权校验**
```
GET /api/license/verify
Authorization: Bearer {token}
X-Device-ID: {device_id}

响应 200:
{
  "code": 200,
  "data": {
    "valid": true,
    "expire_at": 1780000000000
  }
}
```

**解绑设备（管理员发起，或客户端发起换机申请）**
```
POST /api/license/unbind
（需管理员 API Key 或指定客服流程）
```

#### 面向三方卡网（发货 Webhook）

```
POST /api/cards/deliver
Authorization: Bearer {CARDNET_WEBHOOK_SECRET}
Content-Type: application/json

{
  "order_id": "cardnet_order_123",
  "product_id": "sx_monthly",     // 对应本服务端的卡密类型
  "quantity": 1
}

响应 200:
{
  "code": 200,
  "cards": ["SX-XXXX-XXXX-XXXX"]
}
```

### 4.4 Token 设计

```
Token = Base64(payload) + "." + HMAC-SHA256(Base64(payload), SERVER_SECRET)

payload = {
  "card_key": "SX-XXXX",
  "device_id": "abc123",
  "expire_at": 1780000000000,
  "issued_at": 1720000000000
}
```

服务端无状态校验：解码 Token → 验签 → 检查 expire_at。

## 5. 客户端设计

### 5.1 接口层

```kotlin
interface LicenseServer {
    suspend fun activate(cardKey: String, deviceId: String): LicenseResult
    suspend fun verify(token: String, deviceId: String): LicenseResult?
}

data class LicenseResult(
    val success: Boolean,
    val token: String?,     // 激活成功时服务端下发
    val expireAt: Long,     // Unix ms；-1 = 永久
    val message: String
)
```

### 5.2 实现类

```
LicenseServer（接口）
  ├── SxServerLicenseServer   调本项目服务端 API（生产）
  └── DevLicenseServer        debug only，本地校验 DEV 卡密，不请求网络
```

### 5.3 本地 Token 结构

```kotlin
data class LicenseToken(
    val rawToken: String,       // 服务端下发的原始 Token（用于 verify）
    val cardKey: String,
    val deviceId: String,
    val expireAt: Long,
    val activatedAt: Long,
    val lastVerifiedAt: Long
)
// 存储：EncryptedSharedPreferences，JSON 序列化
```

### 5.4 isValid() 逻辑

```kotlin
fun isValid(): Boolean {
    if (BuildConfig.DEBUG && isDevKey()) return true
    val token = loadToken() ?: return false
    if (token.expireAt == -1L) return true
    return TimeGuard.now() < token.expireAt
}
```

### 5.5 SplashActivity 校验流程

```
App 启动
  ├─ isValid() = true  ──► 进主界面
  │                        └─ 后台异步 verify() 刷新 expireAt（不阻塞启动）
  └─ isValid() = false ──► 跳 LicenseActivity（激活页）
```

### 5.6 设备指纹

```kotlin
object DeviceFingerprint {
    // 必须在宿主主进程调用（Hook 层会伪造 AndroidID）
    fun get(context: Context): String {
        val raw = Settings.Secure.getString(
            context.contentResolver, Settings.Secure.ANDROID_ID
        ) ?: Build.SERIAL
        return sha256(raw).take(32)
    }
}
```

## 7. 验收标准

| 场景 | 期望行为 |
|------|---------|
| 三方卡网发货 Webhook 调服务端 | 服务端返回卡密，卡网自动发给用户 |
| 用户输入有效卡密激活 | 客户端调服务端 → 绑定成功 → 返回 Token → 本地存储 → 进主界面 |
| 重复设备激活同一卡密 | 正常（已绑定，返回原 Token） |
| 不同设备激活同一卡密 | 服务端返回「已绑定其他设备」错误 |
| Token 有效，无网络 | 本地校验通过，正常进主界面 |
| Token 过期 | 跳激活页 |
| 管理员后台解绑设备 | 用户重新激活可绑定新设备 |
| DEV 卡密在 release 包 | 拒绝（ClientConfig.isDevKey() + !DEBUG） |
