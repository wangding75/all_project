## 1. 核心决策

| 决策项 | 结论 | 说明 |
|--------|------|------|
| 服务端形态 | **通用卡网接口** | 出抽象接口层；具体实现可换（第三方 SaaS 卡网 / 自建独立部署均为外部服务） |
| 卡密策略 | **简单策略，时长可自定义** | 1 设备绑定；时长由卡网/管理端决定，客户端不硬编码 |
| 设备绑定 | **1 台设备** | AndroidID SHA-256 哈希作为设备标识 |
| 本地存储 | **EncryptedSharedPreferences** | 标准 Jetpack Security 方案 |
| 离线策略 | **本地 Token 到期前可用** | 依赖 TimeGuard 可信时间；到期即拦截，无额外宽限 |
| DEV 卡密 | **仅 debug 包保留** | BuildConfig.DEBUG 区分，release 不接受 DEV 卡密 |

## 2. 架构设计

### 2.1 分层结构

```
UI 层（LicenseActivity）
  └─ 输入卡密 → 触发激活

LicenseManager（状态机）
  ├── loadToken()        读本地 Token
  ├── activate(cardKey)  调 LicenseServer → 保存 Token
  └── isValid(): Boolean TimeGuard + expireAt 判断

LicenseServer（接口，唯一对外契约）
  ├── CardNetLicenseServer   HTTP 实现（对接任意卡网）
  └── DevLicenseServer       debug only，绕过网络

LicenseToken（数据类）   本地持久化结构
DeviceFingerprint        宿主真实设备 ID
```

### 2.2 接口定义

```kotlin
// P-A 的唯一外部契约，不绑定任何具体卡网
interface LicenseServer {
    suspend fun activate(cardKey: String, deviceId: String): LicenseResult
    suspend fun queryStatus(cardKey: String, deviceId: String): LicenseResult?
}

data class LicenseResult(
    val success: Boolean,
    val expireAt: Long,     // Unix 毫秒；-1 = 永久
    val message: String
)
```

## 3. 卡网对接协议（通用 HTTP 适配层）

### 3.1 设计原则

客户端只认 `LicenseServer` 接口，不直接耦合任何卡网品牌。  
`CardNetLicenseServer` 是一个 HTTP 适配器，通过配置切换卡网。

### 3.2 通用卡网 API 约定

绝大多数卡网（爱发卡、发卡网、卡易售、自建 FAKA 等）均提供类似接口，抽取公共子集：

**激活接口**

```
POST {BASE_URL}/activate
Content-Type: application/x-www-form-urlencoded

card_key={cardKey}&device_id={deviceId}&app_key={APP_KEY}&sign={SIGN}
```

响应统一映射到 LicenseResult：

```json
{
  "code": 200,
  "msg": "激活成功",
  "data": {
    "expire_at": 1780000000000,
    "card_key": "SX-XXXX-XXXX"
  }
}
```

**查询接口（可选）**

```
GET {BASE_URL}/status?card_key={cardKey}&device_id={deviceId}&app_key={APP_KEY}&sign={SIGN}
```

### 3.3 配置项

```kotlin
object LicenseConfig {
    const val BASE_URL    = BuildConfig.LICENSE_BASE_URL
    const val APP_KEY     = BuildConfig.LICENSE_APP_KEY
    const val APP_SECRET  = BuildConfig.LICENSE_APP_SECRET  // 不落明文 APK
    const val TIMEOUT_MS  = 10_000L
}
```

APP_SECRET 通过 `local.properties` + BuildConfig 注入，不提交 Git。

### 3.4 签名策略（简单版，可替换）

```
SIGN = MD5(card_key + device_id + app_key + app_secret).uppercase()
```

## 4. 设备指纹

```kotlin
object DeviceFingerprint {
    // 必须在宿主主进程调用，不受 Hook 伪装影响
    fun get(context: Context): String {
        val raw = Settings.Secure.getString(
            context.contentResolver, Settings.Secure.ANDROID_ID
        ) ?: Build.SERIAL
        return sha256(raw).take(32)
    }
}
```

> **注意：** Hook 层会伪造 AndroidID，必须从宿主主进程调用，禁止从沙箱进程内调用。

## 6. LicenseManager 状态机

```
未激活 ──activate()──► 已激活
                           │
              ┌────────────┴────────────┐
              │ expireAt > now()        │ expireAt <= now() 或无 Token
              ▼                         ▼
            有效                       过期/未激活
```

isValid() 核心逻辑：

```kotlin
fun isValid(): Boolean {
    if (BuildConfig.DEBUG && isDevKey()) return true   // debug 旁路
    val token = loadToken() ?: return false
    if (token.expireAt == -1L) return true             // 永久卡
    return TimeGuard.now() < token.expireAt
}
```

## 7. SplashActivity 启动校验流程

```
App 启动
  ├─ isValid() = true  ──────────────► 进主界面
  │                                    └─ 后台异步 queryStatus() 刷新（不阻塞）
  └─ isValid() = false ──────────────► 跳 LicenseActivity
```

本地 Token 有效时不阻塞启动；联网校验完全异步。

## 10. 验收标准

| 场景 | 期望行为 |
|------|---------|
| 有效卡密激活 | 联网成功，跳主界面，Token 本地存储 |
| 无效卡密 | 提示卡网返回的 msg，不跳转 |
| Token 有效，无网络 | 正常进主界面，不阻塞 |
| Token 过期 | 跳激活页，核心功能不可用 |
| DEV 卡密在 release 包 | 拒绝（!DEBUG 时 isDevKey() 直接 false） |
| debug 包 DEV 卡密 | 直接通过，不请求网络 |
| 换设备激活 | 卡网返回「设备已绑定」错误 |
