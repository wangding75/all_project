# 沙箱引擎接口设计（SandboxEngine）

## 1. 目的

隔离 **BlackBox 实现** 与 **闪现业务/UI**，并与 xh 中 `com.lody.virtual` 调用语义对齐，便于对照测试。

---

## 2. 核心模型

```java
/** 沙箱内的一个应用实例 */
class SandboxApp {
    String packageName;
    String label;          // 显示名（可重命名）
    int userId;            // 0=主分身, 1..=克隆
    long installedTime;
    boolean isRunning;
}

/** 本机已安装、可供导入的应用 */
class HostAppInfo {
    String packageName;
    String label;
    Drawable icon;         // 或路径
    String sourceDir;
}
```

## 3. SandboxEngine 接口

```java
public interface SandboxEngine {

    /** 宿主 Application 中初始化引擎 */
    void initialize(Application app);

    /** 引擎是否可用 */
    boolean isReady();

    // ---- 安装 / 卸载 ----

    /** 从本机已安装包导入沙箱 */
    InstallResult installFromHost(String packageName);

    /** 从 APK 路径安装（P1） */
    InstallResult installFromApk(String apkPath);

    /** 卸载虚拟包（所有 user 或指定） */
    boolean uninstall(String packageName, int userId);

    /** 清除分身数据 */
    boolean clearData(String packageName, int userId);

    // ---- 查询 ----

    List<SandboxApp> listInstalled();

    SandboxApp get(String packageName, int userId);

    boolean isInstalled(String packageName, int userId);

    // ---- 生命周期 ----

    /** 启动分身 */
    boolean launch(String packageName, int userId);

    /** 强停 */
    boolean kill(String packageName, int userId);

    void killAll();

    // ---- 多开 ----

    /**
     * 克隆新实例，返回新 userId；
     * 对齐 xh 多用户 / clone 语义
     */
    int clone(String packageName);

    // ---- 快捷方式 ----

    boolean createShortcut(Context context, String packageName, int userId);

    // ---- 重命名 ----

    void setDisplayName(String packageName, int userId, String name);
}
```

### InstallResult

```java
class InstallResult {
    boolean success;
    int userId;
    String message;
}
```

## 4. 与 xh / VA API 对照

| 闪现 SandboxEngine | xh 中可见调用（混淆/示意） | 说明 |
|--------------------|---------------------------|------|
| `initialize` | VirtualCore 启动 | Application 附着 |
| `installFromHost` | `VAppInstallerParams` + install | 导入已装应用 |
| `listInstalled` | `getInstalledApps` / `w(0)` | 列表 |
| `launch` | `launchApp` / VActivityManager | 启动 |
| `uninstall` | uninstallPackage | 移除 |
| `clearData` | clearPackage | 清数据 |
| `clone` / 多 userId | `VUserInfo` / 多用户 | 多开 |
| `createShortcut` | ShortcutHandleActivity 体系 | 桌面入口 |
| 分身配置 | 独立设置 + remote 配置 | 非引擎 API，业务层 |

实现类：`BlackBoxSandboxEngine implements SandboxEngine`。  
测试类：`FakeSandboxEngine`（内存列表，供 UI 无引擎开发）。

## 6. 分身配置仓库

```java
public interface ProfileRepository {
    SpoofProfile getGlobal();
    void saveGlobal(SpoofProfile p);

    SpoofProfile getInstance(String pkg, int userId);
    void saveInstance(String pkg, int userId, SpoofProfile p);

    /** 合并：实例覆盖全局 */
    SpoofProfile resolve(String pkg, int userId);
}

class SpoofProfile {
    LocationConfig location;
    DeviceProfile device;
    NetworkProfile network;
    CameraConfig camera;
}
```

## 7. 启动时 Hook 挂载点

```java
public interface SpoofRuntime {
    /** 在虚拟进程启动目标 App 前调用 */
    void onVirtualClientStart(String packageName, int userId);
}
```

`onVirtualClientStart` 内：

1. `profile = ProfileRepository.resolve(pkg, userId)`  
2. 安装 Location/Device/Network/Camera hooks  
3. 日志：`[SX] spoof installed for pkg=.. user=..`  

具体与 BlackBox 的回调对接点见
[13_BlackBox集成笔记.md](./13_BlackBox集成笔记.md) 与 `engine-bb/` 源码。

## 8. 错误码（建议）

| code | 含义 |
|------|------|
| 0 | 成功 |
| 1 | 引擎未初始化 |
| 2 | 未授权/授权过期 |
| 3 | 安装失败（解析/架构不支持） |
| 4 | 未找到包 |
| 5 | 启动失败 |
| 6 | 权限不足 |
| 7 | 超过分身数量限制 |

## 9. 实现阶段约定

| 阶段 | 引擎实现 |
|------|----------|
| 文档/UI 并行 | `FakeSandboxEngine` |
| 集成周 | 引入 BlackBox 子模块，切换 `BlackBoxSandboxEngine` |
| 以后 | 可增加 `VirtualAppSandboxEngine`（若未来授权） |

DI / 选择方式：

```text
BuildConfig.SANDBOX_ENGINE = fake | blackbox
```
