## 1. 目标与非目标

### 1.1 首发目标（必须可对外说清楚的）

在 **约定钉钉版本范围** + **通用机型** 上，闪现沙箱内：

| ID | 能力 | 最低成功标准 |
|----|------|----------------|
| DT-01 | 导入/启动钉钉分身 | 能进首页/登录页，无必现崩溃 |
| DT-02 | 多开 | ≥2 个 userId 数据隔离（不同账号可登） |
| DT-03 | **相机图片替换** | 打卡/拍照相关路径下，业务拿到的图像为用户设定图（**以实测路径为准**，见 §3） |
| DT-04 | 定位伪装 | 考勤/定位相关读数与配置一致（若钉钉使用的 API 被现 Hook 覆盖；否则补 Hook） |
| DT-05 | 设备指纹 | 基础字段不暴露明显真机冲突（范围以实测清单为准） |

### 1.2 非目标（首发可不承诺）

- 全版本钉钉、全机型、所有活体/人脸方案 100% 过  
- 企微/飞书等同级（可列二期清单）  
- 商业服务端卡密（仍走产品级 P-A）  
- 与 xh 逐版本军备竞赛式对抗  

失败项必须进 **兼容表**，禁止静默当成功。

---

## 2. 与通用能力的关系

```text
通用 Phase 0–4 代码
    │  多开 + 通用 Hook + 相机 PreviewCallback 等
    ▼
钉钉专项（本计划）
    │  针对钉钉实际调用的 Camera/定位/设备 API 补齐 Hook 与策略
    ▼
统一测试波次：模拟器（可选）→ 通用真机 → 钉钉场景清单
    ▼
首发说明：支持范围 + 已知限制
```

**重要：** 当前 `CameraHook` 仅 Camera1 `PreviewCallback` / `takePicture`。  
钉钉若走 **Camera2 / Surface / Native**，**必须在本专项中补路径**，否则不得宣传「支持钉钉换图」。

## 3. 工作包（执行顺序）

### Wave 0 — 基线与情报（先做）

| ID | 任务 | 产出 |
|----|------|------|
| DT-W0-1 | 冻结 **钉钉版本**（如 7.x.x 起止）与测试账号策略 | `docs/26_钉钉兼容矩阵.md` 表头 |
| DT-W0-2 | 在沙箱内装钉钉，记录：能否安装/启动/登录 | 矩阵行：安装/启动 |
| DT-W0-3 | **相机路径摸底**（log/Frida/对照 xh 分析，合法测试账号） | 路径结论：Callback / Camera2 / Surface / 其它 |
| DT-W0-4 | 定位/设备 API 摸底 | 需补 Hook 列表 |

**门禁：** 没有 DT-W0-3 结论，不进入「已支持钉钉相机」宣传，也不关闭 DT-03。

### Wave 1 — 代码补齐（按 W0 结论）

| ID | 任务 | 说明 |
|----|------|------|
| DT-W1-1 | 按摸底结果扩展相机 Hook | 可能含 Camera2、Surface/OpenGL、分辨率对齐；静态图优先 |
| DT-W1-2 | 媒体跨进程路径保持可用 | 沿用/加固 ConfigProvider 字节通道 |
| DT-W1-3 | 定位/设备补 Hook（若钉钉走未覆盖 API） | 最小补齐 |
| DT-W1-4 | 钉钉进程启动稳定 | 崩溃、黑屏、闪退记修 |
| DT-W1-5 | 文档 | 更新 docs/18、22、26：钉钉支持范围与限制 |

**阶段交付门禁（现阶段策略 docs/24）：**

- 代码在 **main commit**  
- `assembleDebug` 成功  
- **可安装启动**闪现  
- 未完成 W2 前：**不得**写「钉钉实测 PASS」  

### Wave 2 — 统一测试与修复（后置集中做）

| ID | 任务 |
|----|------|
| DT-W2-1 | 通用真机 + 约定钉钉版本：DT-01～05 用例表 |
| DT-W2-2 | FAIL 项修复 → 再测 → 更新矩阵 |
| DT-W2-3 | 首发说明：支持/不支持列表对外口径 |

**测试策略（产品已定）：**

1. **现阶段**默认不铺开全量模拟器/真机日常测  
2. **先保证**功能代码齐、可打包安装启动  
3. **最后**针对钉钉（及清单内其它 App）统一测与修

## 5. 下发原则

- **不要**把「通用 CameraHook」直接改名为钉钉完成。  
- **先 W0 摸底，再 W1 改代码，再 W2 统一测。**  
- 执行方每波结束 **commit + 报 hash**；规划方只 review 提交。

---

## 6. 一句话

> **首发卖点=钉钉；通用底座之上必须做钉钉专项：先摸清相机/定位真实路径，再补 Hook，最后统一真机验收。未测不得宣称钉钉可用。**
