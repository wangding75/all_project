## 1. 总览

| 阶段 | 名称 | 周期（建议） | 目标 |
|------|------|--------------|------|
| P0 | 基础工程与 UI 骨架 | 1 周 | 按 xh 信息架构跑通页面；Fake 引擎 |
| P1 | 沙箱多开集成 | 1.5–2 周 | BlackBox 导入/启动/克隆/快捷方式 |
| P2 | 定位 + 设备 + 网络伪装 | 2 周 | 分身内验证通过 |
| P3 | 虚拟相机 + 授权完善 | 1.5–2 周 | 图片/视频预览替换；防回拨 |
| P4 | 打磨与发布准备 | 1 周 | 兼容性、混淆、文档收尾 |

**合计约 7–9 周**（1–2 名熟悉 Android 的开发；引擎踩坑可能上浮）。

```
W1        W2-W3       W4-W5       W6-W7       W8
├─ UI/API ─┼─ BlackBox ─┼─ Spoof ──┼─ Camera ──┼─ Release
│  Fake    │  多开 P0   │  定位设备 │  授权     │  适配
```

## 3. Phase 1 — BlackBox 多开（Week 2–3）

### 目标

M1 P0 需求全部满足。

### 任务

| # | 任务 | 产出 |
|---|------|------|
| 1.1 | 引入 BlackBox 源码子模块 / 复合构建 | `engine-bb` |
| 1.2 | Application 初始化引擎 | `isReady()` |
| 1.3 | `BlackBoxSandboxEngine` 实现 install/list/launch | 真机导入微信等 |
| 1.4 | uninstall / clearData / kill | 详情页可用 |
| 1.5 | clone 多实例 | 两个微信分身 |
| 1.6 | 桌面快捷方式 | 冷启动到指定分身 |
| 1.7 | 32/64 或插件位问题记录与处理 | 适配笔记 |
| 1.8 | 权限与包可见性 | Android 11+ 列表完整 |

### 验收

- [ ] 真机 Android 10 或 13：导入 → 启动 → 登录态与真机隔离  
- [ ] 克隆第二实例数据独立  
- [ ] 快捷方式可用  
- [ ] Host 不因分身退出而崩溃  

### 风险

| 风险 | 缓解 |
|------|------|
| BB 编译失败 | 固定已知可编 commit；减依赖 |
| 某机型启动黑屏 | 机型白名单；Issue 跟踪 |
| 大厂 App 拒开 | 先用普通工具 App 验收多开 |

## 11. 依赖与阻塞升级规则

- 引擎编译阻塞超过 **3 天**：降级继续 Fake UI，并行换 BB fork/commit  
- 某系统 App 无法多开：不阻塞 MVP，记入兼容列表  
- 地图 Key：不阻塞，POI 方案兜底
