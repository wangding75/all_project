## 3. 仓库现状（交接时快照）

### 3.1 已有

| 类别 | 状态 |
|------|------|
| 技术文档 `docs/*` | ✅ 齐全（本目录） |
| Gradle 工程骨架 | ⚠️ 部分（`settings.gradle` / `app/build.gradle` 等） |
| 布局 XML | ⚠️ **有草稿**（约 15 个 layout，未接逻辑） |
| 资源 strings/themes/menu | ⚠️ 有基础 |
| Manifest 中 Activity 声明 | ⚠️ 已写类名，**对应 Java 类大多不存在** |
| 数据模型 `data/*` | ⚠️ 部分 Config/Prefs 类 |
| `LicenseManager` / `TimeGuard` 等 | ⚠️ 工具向代码有草稿 |
| 可安装、可点的 UI | ❌ **无** |
| BlackBox 集成 | ❌ **无** |
| Hook 实现 | ❌ **无** |

### 3.2 明确未完成（按计划做）

1. 全部 Activity / Fragment 的 Java（或 Kotlin）实现  
2. `SxApp`、导航、FakeSandboxEngine  
3. BlackBox 子模块与 `BlackBoxSandboxEngine`  
4. SpoofRuntime 与各 Hook  
5. 真机多开与伪装验收  

### 3.3 开发者心态

- 布局 XML **可复用、可改**，不必推倒；以 [04_UI](./04_UI交互规格.md) 为准校验是否缺页。  
- 数据类草稿 **需 code review 后再用**，可按接口文档调整。  
- **以文档验收为准**，不以「仓库里是否已有半截代码」为准。

## 5. 推荐实现顺序（总计划摘要）

详见 [07_开发计划与里程碑.md](./07_开发计划与里程碑.md)。

```
Phase 0  UI + Fake 引擎（可演示导航）     ← 下一位开发者从这里开工
Phase 1  BlackBox 多开 P0
Phase 2  定位 / 设备 / 网络伪装
Phase 3  相机 + 授权完善
Phase 4  兼容、混淆、发布准备
```

**原则：** 先 Fake 跑通 UI 与配置存储，再接引擎；先多开，再伪装；相机可后置。

## 6. Phase 0 开工清单（给实现同学）

完成即达到 **M1 UI Demo** 里程碑。

### 6.1 工程能编过

- [ ] 用 Android Studio 打开 `sx`，Sync 成功  
- [ ] 补齐缺失类，消除 Manifest 中「找不到 Activity」  
- [ ] `debug` 变体能安装到模拟器/真机  

### 6.2 导航骨架

- [ ] `SxApp`  
- [ ] `SplashActivity` → 延迟跳转 `MainActivity` 或 `LicenseActivity`（策略可配置）  
- [ ] `MainActivity` + 底部三 Tab：首页 / 应用 / 我的  
- [ ] `HomeFragment` 卡片跳转到各设置页  

### 6.3 应用相关（Fake）

- [ ] `FakeSandboxEngine` 实现 [05](./05_沙箱引擎接口.md) 核心方法（内存 List）  
- [ ] 应用列表展示 Fake 数据；空状态文案  
- [ ] 应用选择器：读本机已装应用，点选「加入」写入 Fake 列表  
- [ ] 详情页：启动（Toast 模拟）、克隆、删除  

### 6.4 设置页接 Prefs

- [ ] 定位 / 设备 / 网络 / 相机设置：读写现有或整理后的 Config  
- [ ] 授权页：展示 deviceId、输入卡密走 `LicenseManager`（可先开发卡密）  

### 6.5 验收（Phase 0）

- [ ] 不依赖 BlackBox，可完整点完主路径  
- [ ] 配置杀进程后仍在  
- [ ] 页面与 [04](./04_UI交互规格.md) 主路径无阻断性缺失  

**Phase 0 不要求：** 真多开、真 Hook、地图 SDK、加固。

## 10. 协作约定

1. **改选型先改 ADR**，再改代码。  
2. UI 争议以 [04](./04_UI交互规格.md) + xh `src_restore` 为准。  
3. 业务只依赖 `SandboxEngine`，禁止 Activity 直接 import BlackBox 内部类。  
4. 提交信息说明「做了什么 / 为何」；不提交密钥与地图 Key。  
5. 从 xh 只借鉴 **行为与文案语义**，不复制加固 so 与商业引擎。
