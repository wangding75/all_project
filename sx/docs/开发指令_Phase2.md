# 闪现 (sx) 开发指令 — Phase 2（环境伪装 Hook）

**下发对象：** Android 开发  
**指令版本：** v1.0  
**前置：** Phase 1（BlackBox 多开）评审通过  
**目标里程碑：** M3 伪装可用  
**工期参考：** 约 1.5–2.5 周  

---

## 一、你要交付什么

| 交付 | 说明 |
|------|------|
| 分身内定位伪装 | 坐标/精度/时间戳；反 Mock |
| 分身内设备伪装 | Build / AndroidId / Telephony 等 |
| 分身内网络·基站伪装 | WiFi SSID/BSSID、扫描列表、Cell |
| 配置合并 | 全局 + 分身（package + userId） |
| 探针验收 | SpoofProbe 或等价，可重复验证 |
| 测试记录 | **先模拟器、后通用真机** |

**不做：** 虚拟相机解码、地图 SDK、商业授权服务端、强检测 App 全过承诺。

## 三、硬性约束

1. Hook **仅针对沙箱分身进程**（经 BB 客户端启动回调 / 引擎粘合层）。  
2. UI **禁止**直接依赖 Pine/BB Hook 实现类。  
3. 配置跨进程读取方案必须文档化；主路径避免 `MODE_WORLD_READABLE`。  
4. 机型：**通用机型**；测试：**模拟器通过 → 真机**。  
5. 保持 `SandboxEngine` 边界；不引入未授权 VA。
