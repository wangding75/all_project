## 0. 范围

### 0.1 交付

1. **虚拟相机（分身内）**：图片源替换预览（至少一路 Camera1 或 Camera2）  
2. **视频源（可选增强）**：MP4 循环解码喂帧（E-02，可二期若时间紧则图片优先）  
3. **授权强化**：核心能力（启动分身 / 伪装生效）在未激活或过期时拦截；TimeGuard 网络授时防回拨  
4. **文档**：相机覆盖策略与已知限制  

### 0.2 不做

- 商业服务端卡密中台（产品级 P-A）  
- 地图 SDK、全品牌 ROM  
- 强检测活体全过承诺  

### 0.3 约束

- 相机 Hook 挂在 **虚拟客户端**（同 Phase 2 SpoofRuntime 扩展或 `CameraHook`）  
- 配置用已有 `CameraConfig`（app 模块）+ 建议经 ConfigProvider 增加 `camera` key 或仅全局配置  
- UI 不直接依赖 Pine 实现类

## 2. 执行步骤摘要

1. `CameraHook` + 配置读取；Surface/预览替换图片帧  
2. （可选）MediaCodec 视频循环  
3. `LicenseManager.isActivated` 门闸：Main/启动分身/伪装可选策略  
4. 启动/激活路径调用 `TimeGuard.refreshNetworkTimeAsync` + 校验用 `getTrustedNow`  
5. 模拟器 → 真机；写 `docs` 相机限制说明  

---

## 3. 验收

- [ ] 分身内打开相机预览为设定图片（或视频）  
- [ ] 未激活/过期无法使用核心能力（约定范围写清）  
- [ ] 回拨系统时间不能延长授权  
- [ ] assembleDebug 通过；模拟器→通用真机  
- [ ] 相机策略文档有  

---

## 4. 一句话

> 在分身内实现虚拟相机图片预览（视频可选）+ 授权门闸与防时钟回拨；模拟器再真机验收后停，等 Phase 4。
