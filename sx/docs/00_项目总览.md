## 1. 产品一句话

在宿主机上提供轻量 **应用级沙箱**：导入/多开第三方 App，数据隔离；并可对分身注入 **虚拟定位、虚拟相机、设备指纹、WiFi/基站** 等环境信息，辅以 **卡密授权与防时钟回拨**。

---

## 2. 技术选型（已拍板）

| 层级 | 选型 | 说明 |
|------|------|------|
| 沙箱引擎 | **BlackBox（自维护 fork）** | 不采购 VA 商业授权；能力对齐 VA 系多开模型 |
| 行为规格 | **xh 逆向结论 + PRD** | 对齐功能语义，不复制其引擎/加固/卡密绕过代码 |
| 进程内 Hook | BlackBox 内 ART Hook（Pine 或引擎自带） | 优先沙箱内生效，不强制用户装 LSPosed |
| 可选增强 | LSPosed 模块形态 | 后期：对非沙箱目标的伪装旁路 |
| UI/交互 | **参照星盒 (xh)** | 信息架构、页面清单、文案逻辑对齐；品牌与视觉可自有 |
| 地图 | 一期内置 POI + 手动坐标；二期高德/百度 SDK | 降低启动门槛 |
| 授权 | 自研卡密 + 离线 HMAC Token + 网络授时 | 与沙箱解耦 |
| 目标系统 | **主：Android 10–13**；次：9/14 | 14/15 单列适配里程碑 |

**明确不做：**

- 不以两仪 (Twoyi) 作主引擎  
- 不以 2017 开源 VA 作产品底座  
- 不接入未授权「商业 VA 泄露源码」
