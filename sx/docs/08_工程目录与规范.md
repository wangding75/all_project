# 工程目录与开发规范

## 1. 目标仓库结构

```
sx/
├── README.md
├── docs/                          # 本技术文档
├── settings.gradle
├── build.gradle
├── app/                           # 闪现 Host 应用
│   └── src/main/
│       ├── java/com/sx/app/
│       │   ├── SxApp.java
│       │   ├── ui/                # 页面（参照 xh 信息架构）
│       │   ├── data/              # Config / Prefs / Models
│       │   ├── license/
│       │   ├── service/           # MockLocation 等
│       │   ├── sandbox/           # Engine 接口与 Fake
│       │   ├── spoof/             # Hook 业务（或放 app 内模块）
│       │   └── util/
│       ├── res/
│       └── AndroidManifest.xml
├── sandbox-api/                   # 可选：纯接口 AAR 模块
├── engine-bb/                     # BlackBox fork 封装实现
│   └── src/.../BlackBoxSandboxEngine.java
└── probe/                         # 可选：SpoofProbe 测试 App
```

一期可将 `sandbox-api` / `spoof` 先放在 `app` 模块内，待稳定再拆。

---

## 2. 包名约定

| 包 | 职责 |
|----|------|
| `com.sx.app.ui.*` | Activity / Fragment |
| `com.sx.app.data.*` | 配置模型与存储 |
| `com.sx.app.sandbox.*` | Engine 接口与实现切换 |
| `com.sx.app.spoof.*` | Hook 安装与运行时 |
| `com.sx.app.license.*` | 授权 |
| `com.sx.app.service.*` | 前台服务 |
| `com.sx.app.util.*` | 工具 |

---

## 3. 编码规范

1. Java 17；AndroidX；ViewBinding 可选  
2. **UI 不直接依赖 BlackBox 包名**，只依赖 `SandboxEngine`  
3. 配置读写集中在 Repository，避免 Activity 直接散落 key  
4. 日志 Tag：`SX` / `SX-Spoof` / `SX-Engine`  
5. 字符串进 `strings.xml`，中文产品文案  
6. 危险操作（卸载/清数据）必须确认框  

---

## 4. Git 约定

| 项 | 建议 |
|----|------|
| 分支 | `main` 稳定；`feature/*` 开发 |
| 提交 | 中文或英文完整句，说明为何 |
| 子模块 | BlackBox 用 git submodule 或 monorepo 目录，钉死 commit |
| 禁止 | 提交密钥、地图 Key、未授权第三方完整引擎源码（若协议不允许再分发） |

---

## 5. 构建变体

| Variant | 用途 |
|---------|------|
| `debug` + ENGINE=fake | UI 开发 |
| `debug` + ENGINE=blackbox | 联调 |
| `release` | 发布；minify |

```gradle
// 示例
buildConfigField "String", "SANDBOX_ENGINE", "\"blackbox\""
```

---

## 6. 与 xh 对照开发方式

1. 做功能前先查 `docs/04` 页面与 `xh` 对应 Activity  
2. Hook 项对照 `docs/06` 与 xh `src_clean` import  
3. **禁止**复制星盒 `libvv` / 加固 so 进仓库  
4. 可参考 `xh/spoofer_project` 的定位服务写法（自有包名重写）
